Featured Projects

★ FEATURED PROJECT

Mini-iPaaS Edge Monitoring Hub

IoT Systems C Programming

A fully autonomous IoT monitoring system running on Raspberry Pi 3 — a C engine reads Linux log file sizes via stat() system calls, a Bash wrapper with set -euo pipefail collects live hardware stats from /proc/ and /sys/, builds a JSON payload, and fires it to Discord via cURL Webhook API. A systemd timer runs the pipeline automatically every 5 minutes. All snapshots are stored in a SQLite database for trend analysis.

C / POSIX Bash systemd SQLite cURL Discord API Raspberry Pi 3 Linux ARM64

Networking Security

Configured a secure WireGuard VPN server on Raspberry Pi 3 using PiVPN.
